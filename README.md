<summary><h3>🛠️ Cool stuff I'm working on</h3></summary>
<br>

* 🎯 **Skyfall:** A 3D TPS boss fight/bullet hell, focusing heavily on **encounter design**, exploring **kinematic pattern design** to make enemy movements and attacks highly distinctive and challenging.
* 🧠 **I Against Me:** A 3D FPS psychological horror, where I'm building emergent AI by **mimicking machine learning** to create adaptive, unpredictable behaviors that encourage player's meaningful decision.

</details>

<details>
<summary><h3>🕹️ Where I've learned so far (Industry Experiences)</h3></summary>
<br>

* 👾 **EA (via TekSystems):** Playtested *[Battlefield 6](https://www.ea.com/games/battlefield/battlefield-6)*, analyzing difficulty balancing to help smooth out the overall player experience.
* 🚀 **[Blackbird Interactive](https://blackbirdinteractive.com/):** Implemented and fine-tuned physics logic for an extra-planetary aerospace environment 🛰️. I also got to design new hazards for a VR multiplayer physics-based puzzle game!
